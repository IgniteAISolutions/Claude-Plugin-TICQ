Run the cowork-inbox-triage skill. Read the inbox since the last run, read whole threads rather than latest messages, and put every message in exactly one of the four buckets, leading with whoever is blocked waiting on you. Draft what you can in the person's own voice and say why you stopped on the ones only they can write. Every reply lands as a draft. Never send, never delete, never touch money.
