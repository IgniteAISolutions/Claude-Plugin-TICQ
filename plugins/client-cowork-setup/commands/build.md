Run the cowork-build skill. Check the pre-work gate first and stop if the interviews are missing, naming what is absent. Then work the ten steps in order, one step per message, verifying each with a real test before moving on: read the file back, make the live connector call, watch the scheduled task fire and read what it produced. Anything you could not verify is reported as NOT VERIFIED with what it would take. Finish by walking the acceptance bar, and never call the build live early. Never send, never delete, never touch money.
