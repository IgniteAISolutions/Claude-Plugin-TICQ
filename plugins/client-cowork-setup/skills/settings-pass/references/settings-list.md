# The settings list

Derived from the Cowork product as documented in the Claude Academy course
"Introduction to Claude Cowork" (lessons 2 and 11) and from live builds. Re-verify
names and positions against the live app on the day; `references/volatile-facts.md`
holds the last-verified state.

| # | Setting | Recommended for a new seat | Reason |
|---|---|---|---|
| 1 | Permission mode | Ask before acting | Claude pauses for approval on each action. Move to Act without asking only when the person is actively supervising and the files are trusted, and only after a review date. Cowork always asks before permanently deleting in either mode. |
| 2 | Working folder | One folder for one stream of work | Pointing at Documents or Downloads is letting a new colleague read every file. Scope it. |
| 3 | Model | The current strategist model (Opus 5.5, or Fable 5.1 for the hardest work; see `../../../references/volatile-facts.md`) | Lower the effort before you lower the model. A frontier model at medium beats an older model at maximum. |
| 4 | Effort | High by default; medium for routine drafting; low for mechanical work | From the model-router rule: choose effort first, model second. |
| 5 | Connectors, org level | Enabled by the admin for the tools the firm uses | An admin enables; each person still authorises their own. |
| 6 | Connectors, per person | Authorised by the person, then tested with one live read each | Enabled is not the same as working. Only a live read proves it. |
| 7 | Connector permission frequency | Ask each time for anything that writes; allow reads | Reads are delegable. Writing outward is not. |
| 8 | Web access | On, unless the org has turned it off | Research and source checks need it. If off, name the skills that lose it. |
| 9 | Claude in Chrome site limits | Limit to the sites the firm's work needs | Trust is per site, not per browser. |
| 10 | Scheduled tasks, cloud or local | Decided per task and written on the task | Cloud runs with the laptop shut and cannot see local files. Local sees the files and needs the machine awake. Never leave it to the default. |
| 11 | Memory | On | Without it every session starts from zero. Verify it carries by writing a fact and asking for it in a fresh session. |
| 12 | Usage budget | Set on the day | Somebody who burns a quota in week one concludes the tool is expensive rather than that the budget was never set. |
| 13 | Writing-voice setting in the app | Off, when the workspace holds a voice profile file | Two profiles disagree. The file is the one the skills read and the one the person can edit. |
| 14 | Notifications | On for scheduled-task completion | Otherwise a failing task fails in silence. |
| 15 | Plugins | Only this plugin and what the firm has chosen | Every extra plugin adds triggers that can collide with these. |

Anything not on this list that the screen shows: record it as "left as found" with its
value, so the list improves.
