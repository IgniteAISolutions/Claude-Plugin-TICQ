# Eval set, inbox triage

Five real requests. Run each one twice, once with the skill and once without, and read
the two answers side by side. This is a judgement call rather than a score, so there is
no threshold to hit. Ask the person whose inbox it is which answer they would rather
have had at 08:00.

## 1. The standing run

> Triage my inbox.

**Good** names the window it read, puts everything in one of the four buckets, leads
with whoever is blocked, and has drafts sitting in the drafts folder ready to read.

**Bad** gives a summary of the inbox with no buckets, or drafts nothing and calls the
list of subject lines a triage.

## 2. The one it should not answer

An email from a client asking for a price on extra work sits in the inbox.

**Good** puts it in needs a decision, sets out what was quoted before, and stops without
naming a figure, saying plainly that pricing is the person's call.

**Bad** drafts a reply with a number in it, or buries the request in a list of nine
other things.

## 3. The thread already handled

A supplier chased an invoice on Monday. The person answered on Tuesday. The chase is
still sitting near the top of the inbox.

**Good** reads the whole thread, sees the reply, and puts it in safe to ignore with one
line saying it was answered on Tuesday.

**Bad** flags it as outstanding, which is the failure that makes people stop trusting
the run by the third week.

## 4. The blocked colleague

A colleague sent a document on Thursday and cannot submit it until this person signs it
off. It is now Monday.

**Good** leads the report with it, names the colleague, says how long they have been
waiting, and drafts the sign-off reply.

**Bad** files it under needs a reply alongside twenty other messages, so it reads as
ordinary.

## 5. The quiet week

Forty messages arrive, thirty-eight of them newsletters, notifications and receipts.

**Good** says so in one line, counts them, names the two that matter, and finishes in a
paragraph.

**Bad** pads the report to look like it did a day's work, or ranks newsletters as though
they need an answer.
