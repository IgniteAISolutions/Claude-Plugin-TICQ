# Progress file, the shape

Lives at `System/progress.md` in the seat's workspace. One per person. The coach
writes it; the person can read and edit it.

```
# Progress, <name>

seat started: <date>
role: <role from the interview>
prompts: on

## Skills

| Skill | Runs | Last run | Confident | Notes, in their words |
|---|---|---|---|---|
| /brief | 3 | 2026-09-14 | yes | "that is my morning now" |
| /triage | 2 | 2026-09-12 | no | "put a newsletter in the wrong bucket" |
| /prep | 0 | | no | |
| ... one row per skill that fits the role ... |

## Suggested builds

| Idea | Came from | Status |
|---|---|---|
| Weekly client report | role map | built, /twin 2026-09-11 |
| Supplier chase list | suggestions | next |

## Nudges

- 2026-09-14 Monday: used /brief x3, /triage x2; not touched /prep; suggested /prep
  before the Marchmont call.
```

Confident means three runs and either the person ran it without help or said the
output was right. Skills that do not fit the role (a person with no meetings does not
need `/prep`) are left off the table, with a line saying why, so the coach does not
suggest them.

"coaching complete" on its own line at the bottom stops the Monday nudge and the
opening line. "prompts off" does the same on the person's instruction.
